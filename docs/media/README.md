# Release media

These assets were produced for Strudel Studio using an isolated Neon Drive session with no personal data, API key, or paid generation. They are covered by the repository license; upstream Strudel attribution remains in THIRD_PARTY_NOTICES.md.

- `hero.svg`: self-contained 1600×520 vector artwork using local font fallbacks; no external assets or fonts.
- `studio-dark.png` / `studio-light.png`: real 1440×1040 screenshots of the demo and composition drawer.
- `walkthrough-poster.png`: captioned start of the walkthrough.
- `walkthrough.webm`: silent visual walkthrough with on-screen step captions. The README provides the same steps as text; run Neon Drive locally to hear it.

To recapture, use a separate `STUDIO_DATA_DIR` and `STUDIO_SAMPLE_DIR`, disable the physical MIDI bridge, install Neon Drive, and open Studio in a fresh browser context. Show Lead with Composition selected, then demonstrate Play, the virtual filter controls, and the Export drawer. Never record personal sessions or API credentials. Keep images around 150 KB each and video below 5 MB so the README remains practical to load.
