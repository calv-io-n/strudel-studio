# Solar Tide

Sunlit plucks and glassy arpeggios, with a warm chord lift and a syncopated bass answer.

**172 BPM · D minor · 128 bars · 9 tracks.** About 179 seconds of music, plus the default three-second export tail. Each pattern is editable in its own tab.

## Play it

Follow the [sample setup](../README.md), start Studio, then run `npm run studio:dnb` in a second terminal. Refresh and choose **Sessions → Solar Tide → Composition → Play composition**.

Use track **Solo** to study a part, or open a clip’s source to change its code. **Project → Export → Render & download WAV** renders the full song. The installer preserves an existing named session.

## Arrangement

| Bars / cycles | Section |
| --- | --- |
| 0–16 | Intro |
| 16–32 | Build |
| 32–64 | Drop 1 |
| 64–80 | Breakdown |
| 80–88 | Rebuild |
| 88–120 | Drop 2 |
| 120–128 | Outro |

The second drop varies the drums and melody. Quieter chord and lead patterns give the intro and breakdown space; drum fills and effects mark transitions. See [arrangement.json](arrangement.json) for exact clip placement and [melody.strudel](melody.strudel) for the main hook.

## Sounds

Recorded drums, breaks, bass and synth sounds come from the three [SampleRadar packs](../README.md#download-the-sounds). Synthesized sub bass and original note patterns complete the arrangement. Named sound slots preserve sample references without embedding raw audio in the pattern files.

Sample downloads and sample-containing backups stay local. See the [source and usage notes](../README.md#keep-the-music-and-its-sources).
